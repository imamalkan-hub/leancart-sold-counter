Shows “how many units sold” on the product page.

**Example site:** https://schlafklinikfinder.com

== Description ==

Calculates product sales from completed orders and displays them as social proof on the product page. Encourages purchases and speeds up the buying decision.

= Highlights =
* Single-purpose, lightweight and fast — no bloated code.
* Compatible with WooCommerce 8+ and HPOS (High-Performance Order Storage).
* Sensible defaults; no configuration needed to get started.
* WordPress coding standards and secure CRUD API usage.
* All output is escaped and all input is sanitized.

= Usage =
After installation, go to **WordPress Admin → Settings → LeanCart Sold Counter** to configure
the options. Most settings are enabled by default.

== Installation ==

1. Download the plugin ZIP file.
2. In the admin panel, go to **Plugins → Add New → Upload Plugin** and upload it.
3. Activate the plugin.
4. Configure your preferences at **Settings → LeanCart Sold Counter**.

== Frequently Asked Questions ==

= Is WooCommerce required? =
Yes. This plugin requires WooCommerce 8.0 or newer.

= Is it HPOS compatible? =
Yes. Order data is accessed only through the WordPress CRUD API.
